# Project overview
"SpamGuard: A Naive Bayes Approach to SMS Filtering" is a machine learning project focused on classifying SMS messages as either spam or ham (legitimate). The primary goal of the project was to predict whether a given SMS message belongs to the spam category or the ham category, with an emphasis on handling the imbalance in the dataset, as ham messages are more frequent than spam messages. The project employs the Naive Bayes classification algorithm, with a specific implementation of Bernoulli Naive Bayes, to make these predictions. Additionally, performance evaluation was carried out using the confusion matrix and AUC-ROC curve for an accurate assessment of the model’s effectiveness in classifying SMS messages.
